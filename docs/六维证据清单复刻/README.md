# 案例 · 六维证据清单复刻

> 源图片：`004-六维证据清单.png`（《准备度评估的六维证据清单》信息图，1728×972）
> 复刻方式：六步标准流程（见 [`../WORKFLOW.md`](../WORKFLOW.md)）
> 本案例与既往案例不同：**两个生成脚本随案例归档于本目录**（`build_html.py` / `build_pptx.py`），可独立复现全部交付物。

| 文件 | 说明 |
|---|---|
| `004-六维证据清单.png` | 源图片（上传原图） |
| `build_html.py` | 生成脚本①：输出 HTML+SVG（1728×972 画布，全真实 `<text>`、独立 `data-unit` 最小单元、零位图） |
| `六维证据清单复刻.html` | 交付物①：HTML+SVG |
| `build_pptx.py` | 生成脚本②：python-pptx 原生文本框+形状（1728×972px → 13.333×7.5in，Picture=0） |
| `六维证据清单复刻.pptx` | 交付物②：原生 PPTX（197 个形状，全部可单独编辑/拖动） |
| `六维证据清单复刻_PPT预览.pdf` | PPTX 经 LibreOffice 渲染的校验用 PDF |

## 复现

```bash
python3 build_html.py    # 依赖：无（纯标准库）；截图校验需 playwright + chromium
python3 build_pptx.py    # 依赖：python-pptx；复用 ../workbench/scripts/pptx_lib.py
```

## 分析与校验结论

- **版面实测**：标题区 0–105 / 表头 110–165 / 六行 165–766（行高 ≈100.2）/ 评分带 784–888 / 页脚条 900–950；列边界 x = {12, 353, 810, 1335, 1716}。
- **配色采样**：表头/评分标签 `#26445C`，行徽标六色板 `[#27445B, #687355, #988270, #7B748F, #6C775A, #8C8075]`，评分徽标五色板（徽标1 为 `#8B8A97`，与表格徽标1 的藏青不同），页脚条 `#EFF3F7`，水印 `#A9ABAE`。
- **字号实测**：标题 66 / 问句 32 / 维度名与负责人 30 / 要点 28 / 表头 28 / 评分卡标题 26 / 副标题 19 / 页脚 25 / 水印 54。
- **HTML vs 原图**：1728×972 逐像素比对，平均绝对差 23.3/255；剩余差异主要为字体渲染本底与手绘图标风格差，版式/配色/文字内容一致。
- **PPTX**：LibreOffice 渲染后与原图对照，表格、评分带、页脚、水印版式一致；文字基线采用 `add_text_baseline`（top = baseline − 1.10×size）。
- **图标（14 种，HTML/PPTX 共享几何）**：维度列 靶心/齿轮/圆柱/云/双人/盾牌勾；证据列 文档柱图/组织树/文档放大镜/服务器堆/人形展板/文档盾牌；负责人实心人形；页脚文档勾；水印微信双气泡。`gear_pts`/`shield_pts`/`arc_pts` 定义在 `build_html.py`，`build_pptx.py` 直接 import 保证两侧一致。
