# 案例 · 能力缺口判断复刻 v2（独立全流程重跑）

> 源图片：`005-能力缺口判断.png`（《准备度评分与能力缺口诊断》仪表盘，1728×972）
> 复刻方式：六步标准流程（见 [`../WORKFLOW.md`](../WORKFLOW.md)）
> **与 [`能力缺口判断复刻`](../能力缺口判断复刻/)（v1）的区别**：本案例为全新会话中的独立重跑——
> 从原图重新逐像素测量（v1 测量结论未作输入），规格书以 `spec.py` 单一数据源喂养双产线，
> 组件库（`svg_lib.py` / `pptx_lib.py`）与全部脚本随案例归档，可零外部依赖复现。

| 文件 | 说明 |
|---|---|
| `005-能力缺口判断.png` | 源图片（上传原图） |
| `spec.py` | **布局规格书**（坐标/配色/文案三表合一，双产线唯一数据源） |
| `svg_lib.py` | SVG 组件库：靶心/齿轮/圆柱/笔记本/双人/盾牌/微信气泡，输出带 `id` 最小单元 |
| `pptx_lib.py` | PPTX 助手库：EMU 换算 / PIL 量宽 / 中文字体 a:ea+a:cs 双保险 / 统一关阴影 |
| `build_html.py` | 生成脚本①：HTML+SVG（全真实 `<text>`、组件带 id、零位图） |
| `build_pptx.py` | 生成脚本②：python-pptx 原生文本框+形状（Picture=0） |
| `能力缺口判断复刻v2.html` | 交付物①：HTML+SVG（1728×972，75 `<text>` / 174 id / 位图 0） |
| `能力缺口判断复刻v2.pptx` | 交付物②：原生 PPTX（194 形状 = 75 文本框 + 自选图形/线条/自由多边形，16:9 EMU 12192000×6858000） |
| `能力缺口判断复刻v2_PPT预览.pdf` | PPTX 经 LibreOffice 渲染的校验用 PDF |
| `verify_deliverables.py` | 终检脚本（15 项断言，当前 15/15 通过） |
| `render_html.py` / `diff.py` | 截图与 16px 块聚合 diff 工具（第一闭环用） |
| `校验证据/` | HTML 并排对比 / PPTX 渲染并排对比 / diff 热力图 |

## 复现

```bash
python3 build_html.py            # 依赖：标准库
python3 build_pptx.py            # 依赖：python-pptx、Pillow
python3 verify_deliverables.py   # 终检（需 python-pptx、Pillow）
# 截图闭环（可选）：playwright + chromium + numpy
python3 render_html.py && python3 diff.py
```
