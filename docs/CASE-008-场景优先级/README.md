## 实战新坑（本案例新增经验）

1. **LibreOffice 默认阴影**：python-pptx 自选图形自带 `<p:style>` 主题引用，仅 `shadow.inherit=False`
   不足以消除 LibreOffice 按 effectRef 渲染的阴影——必须在 `no_shadow` 里把 `<p:style>` 一并剥离
   （本案例 40.28→27.20 的关键修复，最小复现见 pptx_lib.py 注释）。
2. **基线→文本框顶换算**：LibreOffice 行盒使墨迹顶部低于「baseline-0.86×size」约 0.12×size，
   实测系数应取 **top = baseline − 0.98×size**（HTML/SVG 无此问题）。
3. **文本框居中**：用对称框 + `align='c'`，不要「左对齐 + 手减一半宽度」（会整体左移）。
4. **JPEG 压缩图取色**：文字颜色必须取 <80 阈值的核心像素中位数，<140/150 的中位数会被 AA 边缘抬亮。
