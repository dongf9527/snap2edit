# 案例 · 能力缺口判断复刻

> 源图片：`005-能力缺口判断.png`（《准备度评分与能力缺口诊断》仪表盘，1728×972）
> 复刻方式：六步标准流程（见 [`../WORKFLOW.md`](../WORKFLOW.md)）
> 与 004 案例相同：**两个生成脚本随案例归档于本目录**（`build_html.py` / `build_pptx.py`），可独立复现全部交付物。

| 文件 | 说明 |
|---|---|
| `005-能力缺口判断.png` | 源图片（上传原图） |
| `build_html.py` | 生成脚本①：输出 HTML+SVG（1728×972 画布，全真实 `<text>`、独立 `data-unit` 最小单元、零位图） |
| `能力缺口判断复刻.html` | 交付物①：HTML+SVG（111 个 data-unit） |
| `build_pptx.py` | 生成脚本②：python-pptx 原生文本框+形状（1728×972px → 13.333×7.5in，Picture=0） |
| `能力缺口判断复刻.pptx` | 交付物②：原生 PPTX（187 形状 = 72 文本框 + 79 自选图形 + 20 线条 + 16 自由多边形，全部可单独编辑） |
| `能力缺口判断复刻_PPT预览.pdf` | PPTX 经 LibreOffice 渲染的校验用 PDF |

## 复现

```bash
python3 build_html.py    # 依赖：无（纯标准库）；截图校验需 playwright + chromium
python3 build_pptx.py    # 依赖：python-pptx；复用 ../workbench/scripts/pptx_lib.py
```

## 分析与校验结论

- **版面实测**：主标题基线 88（字号≈76）；左表格 x=19..1016，表头 129..206（列界 233/389/705），六行行心 251/323/397/475/553/630（行界 286/359/436/514/592），合计行 672..766（子列界 597/810）；右面板灰标题条 x=1032..1711 y=127..210，条形行心 262/339/420/502/582/664，竖分隔线 x=1206；底部灰带 y=795..838，行动盒 y=850..936（盒起点 143/714/1272），水印 icon+文字压于盒 2/3 之上。
- **配色采样**：表头 `#253E56`；行主题色 图标圆 `[#223952,#616A4E,#6A594A,#76718D,#283A52,#61694C]`，现状条 `[#455E7A,#828B6E,#99897A,#88849D,#4A637D,#848C6F]`；右面板徽标/条 `[#5F684A/#7A8364, #7C6B59/#978678, #7A7491/#88859D, #293D55/#3A5672, #616A4B/#7B8565, #7C6957/#978677]`（注意：原图中人才行在左表为藏青、在右面板为紫灰，按原图原样复刻）；进度条轨道 `#D7DDE4`，合计行底 `#EAEDF1`，灰带 `#F2F4F7`，水印 `#ACAFB4`。
- **特殊细节**：行 1（战略）目标条带 **深色前段**（#264059，约 53px）+ 行色后段的堆叠画法，行 5（人才）目标条整体深藏青 #2B455F——均按原图原样复刻；合计行三个指标（加权现状 2.75 / 加权目标 3.95 / 差距 1.20）分别用深藏青/橄榄/褐三色。
- **字号实测**：主标题 76 / 表头 28 / 满分5 21 / 维度名 27 / 权重与评分数字 26 / 合计值 36 / 面板标题 33 / 面板行名 28 / 条形值 31 / 底带标题 30 / 行动名 27 / 水印 50。
- **HTML vs 原图**：1728×972 逐像素比对，平均绝对差 10.6/255；剩余差异主要为原字体的字重/字宽设计（原图用更窄更重的黑体）与手绘图标风格差，版式/配色/文字内容一致。
- **PPTX**：LibreOffice 渲染后与原图对照平均差 15.4/255，表格、条形图、合计行、行动区、水印版式一致；LibreOffice 文字渲染较基线公式整体偏高约 5px，已在 `txt()` 内做 +5px 校正。
- **图标（7 种，HTML/PPTX 共享几何）**：表格列 靶心飞镖/齿轮/实心圆柱/笔记本/双人/盾牌轮廓；底部 数据圆柱/盾牌/双人（复用同几何，尺寸 58）；水印微信双气泡。`gear_pts`/`arc_pts` 定义在 `build_html.py`，`build_pptx.py` 直接 import 保证两侧一致；圆柱/双人/微信在 PPTX 侧用 freeform+贝塞尔采样复现。
